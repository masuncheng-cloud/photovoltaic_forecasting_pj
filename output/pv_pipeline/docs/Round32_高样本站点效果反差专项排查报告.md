## 8. 判断建议

- 如果高样本差站点的 `test_pred_actual_ratio` 远离 1，说明是系统性高估/低估。
- 如果 `capacity_factor_shift_mean` 或 `capacity_factor_shift_p95` 很大，说明训练期和测试期出力分布不一致。
- 如果测试期 0 值/低出力比例高，说明测试期运行状态异常可能主导误差。
- 如果真实功率与辐照相关性低，而预测功率与辐照相关性高，说明模型按气象预测正常发电，但站点实际受非气象因素影响。
- 如果重复记录存在，必须先修复重复记录，否则样本量和城市聚合可能被扰动。
