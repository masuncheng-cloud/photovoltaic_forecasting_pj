根因定位：`export_interactive_dashboard_data.py` 中的 `export_hourly_prediction_summary` 函数使用了**错误的计算口径**：

```python
# 错误：把所有站点的行混在一起按小时 groupby
eval_df.groupby("hour").apply(lambda g: RMSE / capacity_median * 100)
```

这相当于把所有站点的误差放在一个池子里算 RMSE，而不是先按站点分别算 RMSE 再平均。两种口径的差异约为 **2 倍**，完全解释了 31-37% vs 13-16% 的差距。

## 二、正确口径定义

逐小时"站点平均 NRMSE"应定义为：

```text
1. 对每个 (site_id, hour) 组合，在测试集该小时所有日期上计算 RMSE
2. NRMSE_site_hour = RMSE_site_hour / capacity_mw × 100%
3. 站点平均 NRMSE_hour = mean(NRMSE_site_hour across all sites)
```

这正是 Round45 诊断脚本使用的口径，与报告一致。
