## 六、注意事项

1. **每次 `git add` 后务必 `git status` 确认**没有误加 `.pkl`、`.pth`、`.png`、`.zip` 文件
2. **如果 push 报文件过大**，立即 `git restore --staged` 取消暂存大文件，检查 `.gitignore`
3. **模型文件（pkl）和原始数据**始终保留在云服务器本地，不需要也不应该上传到 GitHub
4. **`post-commit` 钩子**已在本地配置，每次 commit 后自动推送；如果想暂停自动推送，临时将 `.git/hooks/post-commit` 重命名为 `post-commit.bak`
