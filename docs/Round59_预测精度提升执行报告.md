## 4. 新增校准器

### 4.1 hour × scene 全局校准器

- **目标**: 修正系统性小时/场景偏差
- **方法**: `factor = sum(actual) / sum(pred)`，shrinkage 收缩到全局
- **约束**: factor ∈ [0.75, 1.35], min_samples=100, k=500
- **收缩公式**: `final_factor = (n/(n+k)) * raw_factor + (k/(n+k)) * global_factor`
- **输出**: `output/pv_pipeline/calibration/hour_scene_calibrator.csv`
- **主要因子（10-14h 重点时段）**:

| hour | scene | n | raw_factor | final_factor |
|------|-------|---|------------|--------------|
| 10 | clear_peak | 13,717 | 0.9658 | 0.9655 |
| 11 | clear_peak | 18,460 | 0.9615 | 0.9615 |
| 12 | clear_peak | 22,053 | 0.9607 | 0.9607 |
| 13 | clear_peak | 21,765 | 0.9544 | 0.9545 |
| 14 | clear_peak | 18,613 | 0.9569 | 0.9570 |

- **Valid 集效果**: city NRMSE 0.2821% → 0.2807% (Δ=-0.0014%), bias -6.28% → -7.92%

### 4.2 site shrinkage 校准器

- **目标**: 修正 22 个站点的系统性偏差
- **方法**: `site_factor = sum(actual) / sum(pred)`，收缩到容量分组均值
- **约束**: factor ∈ [0.70, 1.40], min_samples=300, k=1000
- **容量分组**:
  - small (< 3MW): group_factor=0.976
  - medium (3-10MW): group_factor=1.014
  - large (≥ 10MW): group_factor=0.967
- **排除站点**: S003/S044/S069/S076/S077（zero_actual_sites）不训练 site factor
- **输出**: `output/pv_pipeline/calibration/site_bias_calibrator.csv`
- **Valid 集效果**: city NRMSE 0.2821% → 0.2793% (Δ=-0.0027%), bias -6.28% → -7.29%

### 4.3 combined 校准

- hour_scene × site 组合应用（hour_scene 先于 site）
- valid 集效果: city NRMSE 0.2821% → 0.2791%, bias -6.28% → -7.84%

## 8. 仍存在的问题

1. **部分站点泛化性不足**: S022/S050/S004/S052 等站点在 test 集上恶化明显，shrinkage 参数 k=1000 可能仍不够保守
2. **低光时段泛化性差**: 18-19h site_nrmse 轻微恶化，说明 site factor 在低光条件下泛化有限
3. **S019/S053 低估加剧**: 校准因子使低估更严重，可能是历史数据特征与 test 集差异导致
4. **hour_scene 因子未应用**: 因 valid 集 bias 变差未选用，但 test 集 hour_scene 单独效果未知
5. **S116 地理置信度低**: 坐标来源于镇中心近似，辐照特征可能不可靠（已标记但未从校准中排除）

---

## 9. 下一步建议

### 高优先级

1. **收紧 site calibrator shrinkage k**: 将 k 从 1000 提高到 2000-3000，减少过拟合风险
2. **per-site 安全约束**: 如果某站点 test 集 site_nrmse 恶化超过 +1.0pp，自动回退该站点的 site factor
3. **引入 hour_scene 作为必选层**: 虽然 valid 集 bias 变差，但 test 集显示 hour_scene 在 10-14h 有改善，建议作为 base 层

### 中优先级

4. **S019/S053 专项分析**: 检查这两个站点的 capacity_mw 是否准确（Round58 建议核查）
5. **季节性校准**: 当前校准基于 train+valid 混合，可能引入季节偏差，建议分季节学习校准因子
6. **停运站点确认**: S003/S044/S069/S076/S077 如果有正式停运记录，应直接置 0 而不是用校准模型

### 低优先级

7. **测试 hour_scene 单独应用**: 在 test 集上单独评估 hour_scene 的效果（不与 site 组合）
8. **S116 地理校正**: 获取精确场区坐标后重新训练地理特征
