## 1. 问题发现与修复

### 1.1 首次运行失败（10:15 启动）

**失败位置**: Stage 6 `evaluate_layers.py`

**错误**:

```
FileNotFoundError: [Errno 2] No such file or directory:
  '/root/autodl-tmp/photovoltaic_forecasting_pj/output/pv_pipeline/metrics/distributed_metrics.csv'
```

**根因**: `train_distributed_model_v159.py` 实际生成的文件名为 `distributed_metrics_v159.csv`，但 `evaluate_layers.py` 硬编码读取 `distributed_metrics.csv`。

### 1.2 修复内容

**文件**: `stages/04_evaluation/evaluate_layers.py`

修改第 18-20 行，将硬编码路径改为优先读取 v159 版本：

```python
# 修复前
dist = pd.read_csv(paths.metrics / 'distributed_metrics.csv')

# 修复后
dist_path = paths.metrics / 'distributed_metrics_v159.csv'
if not dist_path.exists():
    dist_path = paths.metrics / 'distributed_metrics.csv'
dist = pd.read_csv(dist_path)
```

### 1.3 修复流水线末尾验收脚本

**文件**: `scripts/train_fixed.py` 函数 `assert_final_metrics_valid`

`assert_final_metrics_valid` 在主进程直接调用（而非通过子进程 `run_script`），缺少 `sys.path` 导致 `No module named 'pv_forecasting'`。修复方法：

```python
# 在函数开头添加
_src = ROOT / "src"
if str(_src) not in sys.path:
    sys.path.insert(0, str(_src))
```
