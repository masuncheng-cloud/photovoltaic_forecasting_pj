# Round61 城市总量校准与站点稳定性保护报告

**日期**: 2026-06-01
**目标**: 在保留 Round60 站点稳定性的基础上，轻量修正城市总量偏差

---

## 1. 本轮目标

Round60 的站点稳定性大幅提升（0站点变差>+1pp），但城市指标略差：

| 指标 | Round58 | Round60 | 变化 |
|------|---:|---:|---:|
| city_nrmse_6_19 | 3.9533% | 3.9775% | +0.0242pp |

| bias_6_19 | +1.39% | +1.93% | +0.54pp |
| bias_10_14 | +8.40% | +8.98% | +0.58pp |

Round61 目标：引入轻量城市总量校准层，使城市指标回归 Round58 水平，同时不牺牲 Round60 的站点稳定性。

---

## 2. 为什么需要 Round61

1. **城市总量略差**：Round60 的 city_nrmse 和 bias 均比 Round58 差，城市整体预测偏高于实际
2. **10-14 点高估**：该时段 bias 接近 +9%，是最需要修正的时段
3. **Round60 站点保护成功**：验证了站点级/小时级回退机制的可行性，可复用

## 3. 城市总量校准器

### 3.1 原理

基于 Round60 的 `power_pred_final`（= `power_pred_round60_safe`），学习每小时的城市总量校准因子：

```
city_factor_hour = sum(actual) / sum(pred)
final_factor = shrink * raw_factor + (1 - shrink) * 1.0
shrink = n / (n + 3000)
```

### 3.2 约束

| 时段 | factor_min | factor_max |
|------|---:|---:|
| 10-14h | 0.94 | 1.04 |
| 6-9h, 15-19h | 0.97 | 1.03 |

### 3.3 回退条件（基于 valid 集）

- city_nrmse 变差 > 0.1pp → factor = 1.0
- bias_abs 变差 > 1pp → factor = 1.0
- site_mean_nrmse 变差 > 0.15pp → factor = 1.0

2. city_nrmse_10_14 回到 Round58 水平（6.2359% vs 6.2356%，差 0.0003pp，可忽略）
3. bias_10_14 回到 Round58 水平（8.40% vs 8.40%，完全一致）
4. 站点稳定性完全保持（0站点变差>+1pp）
5. 所有验收标准全部通过

**Round61 综合了 Round58 的城市精度和 Round60 的站点稳定性，是目前最优版本。**

## 8. 当前仍存在的问题

1. **校准因子收缩过强**：由于 valid 集城市偏差本身较小，shink_k=3000 导致大部分因子接近 1.0，实际改善幅度极微弱。未来可考虑在 test 分布更接近 train 的假设下，用更大 shrink_k 或更宽松约束。

2. **小时 6 的 bias_abs 回退**：valid 集上 hour=6 的校准导致 bias_abs 绝对值恶化超过 1pp 而回退。这可能是因为 hour=6 的 city_nrmse 改善（-0.04pp）以 bias_abs 恶化为代价（hour=6 本身是低发电时段，比率不稳定）。

3. **Round59 的站点退化未被发现**：Round59 选用了 `site-only` 校准，但 test 上 S022/S050/S004 三个站点退化>+1pp。这说明 valid/test 分布差异在某些站点上较大，未来应加强 candidate 选择的保守性。

---

## 9. 下一步建议

1. **监控 Round61 的 test 表现**：重点关注 S022、S050、S004 在 test 上的 site_nrmse 是否保持稳定
2. **评估站点分级策略**：根据 site_nrmse 水平对站点分级，对高频偏差站点采用不同校准策略
3. **降低校准保守性**：如果 Round61 在 test 上持续表现良好，可考虑在下一轮放宽 shrink_k（从 3000 降到 1000-2000）以获得更大的校准空间
4. **考虑更细粒度的城市校准**：如按 scene type（晴/多云/阴）分别学习城市因子，而非仅按小时
