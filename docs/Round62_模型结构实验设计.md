# Round62 模型结构实验设计

## 1. 为什么进入模型结构层

Round59-Round61 的校准主要修正系统性偏差，但提升幅度有限：
- 城市总量校准因子极接近 1.0（收缩导致）
- 继续调整校准参数容易在城市总量和站点稳定性之间来回摇摆
- 后处理层的上限已经显现

## 2. 当前主要误差模式

| 时段 | 误差特征 | 证据 | 可能原因 |
|------|----------|------|----------|
| 7点 | 低估（bias 偏负） | Round61 test bias=-1.1%（7点） | 弱光启动阶段建模不足 |
| 17点 | 低估（bias 偏负） | Round61 test 17点 | 傍晚下降阶段建模不足 |
| 10-14点 | 高估（bias 偏正） | bias_10_14=+8.40% | 强辐照/峰值阶段过估 |
| low场景 | 低估 | 残差分布偏负 | 弱辐照特征不足 |
| 站点差异 | 持续偏差 | S012/S032/S053 | 容量/映射/站点异质性 |

## 3. 实验方向

### 3.1 发电状态分类器

**目标**：先判断该小时是否有效发电，再预测功率。

三种状态：
- `active`: 正常发电（预测应有功率输出）
- `weak`: 弱发电（预测低功率）
- `inactive`: 无发电（预测为0）

关键设计：
- 基于 GHI、太阳高度角、scene_v151 的阈值规则
- 或基于历史 zero_ratio、positive_ratio 的统计规则
- 作为预处理层，后续预测模型根据状态调整

### 3.2 分场景残差模型

保留现有 Round61 预测作为基线：

```
P_final = P_base + residual_correction
```

按场景拆分训练：

| 场景 | 时间段 | 特征 | 残差修正目标 |
|------|--------|------|-------------|
| dawn | 6-8h | 太阳升起，GHI 低 | 减少低估 |
| day_clear | 9-16h, clear_peak | 强辐照 | 减少高估 |
| day_cloudy | 9-16h, mid/low | 中弱辐照 | 减少低估 |
| dusk | 17-19h | 太阳落下，GHI 下降 | 减少低估 |

残差修正方式：
- 每场景独立训练一个轻量模型（如 Ridge/Lasso）
- 特征：辐照相关特征、时间特征、站点元特征
- 不重训主预测模型

### 3.3 站点特性增强

在残差模型中加入站点元特征：

```
- station historical PR (发电效率)
- capacity bucket (容量分桶)
- zero_ratio (历史零发电比例)
- positive_sample_count (有效样本数)
- geo_confidence (地理置信度)
- long_term_bias (长期偏差方向)
```

## 4. 实验边界

- **不使用 test 调参**：所有参数/场景/阈值在 valid 上选择
- **Round61 作为固定 baseline**：任何实验不能覆盖 Round61 的正式结果
- **offline candidate 机制**：新模型以 candidate 列输出，不直接覆盖 `power_pred_final`
- **自动回退**：若候选在 valid 上不满足安全约束，自动保留 Round61

## 5. 验收指标

| 指标 | 要求 |
|------|------|
| site_mean_nrmse_6_19 | 优于 Round61 或不高于 +0.1pp |
| city_nrmse_6_19 | 不高于 Round61 +0.1pp |
| 10-14 city_nrmse | 不高于 Round61 |
| 7/17 bias_abs | 下降（改善低估/高估） |
| 变差 > +1pp 站点数 | 0 |

## 6. 风险

1. **数据质量限制**：异常 0 值、停运、限电无法靠模型完全解决
2. **辐照特征限制**：没有地面实测辐照，局地云和遮挡难以完全建模
3. **季节分布漂移**：valid 与 test 季节不同，残差模型可能过拟合 valid
4. **站点异质性**：缺少屋顶类型、倾角、朝向等结构化信息
